## NovaStar64 1.0.0

The first release of NovaStar64, a Nintendo 64 emulator with a launcher, save states with rewind, and a graphics
pipeline written from scratch. It comes without games: you add your own legally obtained ROM images.

### What you get

- **A launcher with a library.** Home, Library, Recent and Favorites, a pause menu with four save-state slots (each with
  a picture) and a rewind strip. Everything can be reached from the keyboard, and a controller can drive the menus too.
- **Settings that explain themselves.** One row per option with a line of help, saved at once. Interface size from 100%
  to 200%.
- **The Simulator.** A workbench for each game: wire a Nintendo 64, a TV, controllers, Rumble Paks and the cartridge
  together, and give that game its own speed, CPU core, graphics driver, resolution or save chip.
- **Rumble that you can feel on screen.** A Rumble Pak shakes the window a little, and you set how much.
- **Graphics on Vulkan and OpenGL**, 1x to 8x internal resolution, texture packs, and an experimental ray tracer.
- **Four controllers**, rebindable, with the N64's analog range.

### Tested

Super Mario 64, Ocarina of Time and Majora's Mask (NTSC-U) are played through; nothing else has been checked
systematically, so expect rough edges with other games. Please report what you find. Tested on macOS (Apple Silicon)
and Windows.

### Downloads

| Platform | File |
|---|---|
| macOS, Apple Silicon (macOS 13.3 or later) | `NovaStar64-1.0.0-macOS.dmg` |
| Windows, 64-bit | `NovaStar64-1.0.0-Windows-Setup.exe`, or `NovaStar64-1.0.0-Windows-portable.zip` |
| Linux, x86-64 (Ubuntu 24.04 or newer) | `NovaStar64-1.0.0-Linux-x86_64.AppImage` (not tested on a Linux machine yet) |

Each file has a `.sha256` checksum beside it. The macOS and Windows installers are not code-signed, so your system shows
a one-time warning the first time; the README says how to get past it. Intel Macs and other Linux systems can build from
source.

### Good to know

- No Controller Pak or Transfer Pak, no netplay, no RetroAchievements yet.
- Majora's Mask has some incomplete visual effects.
- Moving through the launcher's menus with a controller has not been tried on real hardware yet.
- NovaStar64 collects nothing and makes no network connections.

NovaStar64 is free software under the GPL-2.0. Its CPU core and RSP began as a fork of Project64 and are credited as such.
